## About

I'm a software engineer based in Lagos, Nigeria, writing code since 2021 — five years of building and
shipping software. I build systems end to end: the database schema and migrations, the authentication and API
layer, background workers and job queues, the interface, and the deployment that keeps it running. That range
is deliberate — the hard problems usually live where the layers meet, not inside any single one.

Lately most of my work is AI-native. I integrate large language models where they genuinely help, and I spend
just as much effort on the parts that make AI software dependable: structured outputs, retrieval from real
documents, provider fallbacks, cost tracking, and honest failure states when a model cannot deliver.

I also build on-chain. I've written Solidity contracts for token launches and liquidity migration, tested them
against an in-process EVM, and built the analytics product around them.

Since 2023 I've tutored developers in web and mobile development. Teaching forces precision about
architecture, and it shows in how I document and structure code.

- **Product engineering** — full-stack web apps, dashboards, SaaS platforms and internal tools
- **Mobile** — cross-platform Android builds with React Native, Expo and offline-first SQLite storage
- **AI systems** — RAG pipelines, multi-step agents, document intelligence, LLM provider orchestration
- **Backend** — REST APIs, PostgreSQL schema design, background jobs, queues, webhooks, multi-tenant access control
- **On-chain** — Solidity smart contracts, bonding-curve mechanics, dApp front ends

## Featured Projects

### [NovelForge](https://github.com/Obiorachibuike/NovelForge) — AI novel-writing and publishing studio

AI writing tools tend to generate whole books and lose the plot along the way. NovelForge takes the opposite
approach: one chapter at a time, gated by the author's approval, with a persistent Story Bible (characters,
world rules, timelines, plot threads) that keeps a long manuscript consistent. It covers the full pipeline —
cover generation, outline, sequential writing, consistency checks and export to DOCX, PDF, EPUB, TXT and
Markdown — on durable background generation with `pg-boss`, resumable job records and per-user cost tracking.

`Next.js 14` · `TypeScript` · `PostgreSQL` · `pg-boss` · `Tiptap` · `Stripe` · `Cloudinary`
&nbsp;·&nbsp; [Live](https://novel-forge-seven.vercel.app) &nbsp;·&nbsp; [Source](https://github.com/Obiorachibuike/NovelForge)

### [Achilyon](https://github.com/Obiorachibuike/Achilyon-_Softwares) — token discovery and fair-launch platform

A launchpad and market-analytics terminal for emerging crypto markets. The on-chain side is a Solidity
bonding-curve factory, an ERC-20 with `permit`, and a Uniswap V2 migrator that graduates completed curves into
a pool with burned LP tokens — tested on an in-process EVM against the official Uniswap V2 bytecode. The
product around it adds market tables with transparent trending scores, token pages with charts, a six-step
launch wizard, a wallet trading panel, moderation tools and risk signals. Demo mode is clearly labelled
wherever data is simulated.

`Solidity` · `Hardhat` · `viem` · `Next.js` · `React` · `TypeScript`
&nbsp;·&nbsp; [Live](https://achilyon-softwares.vercel.app) &nbsp;·&nbsp; [Source](https://github.com/Obiorachibuike/Achilyon-_Softwares)

### [ClipFoam](https://github.com/Obiorachibuike/ClipFoam) — self-hostable long-video to short-form pipeline

An open-source alternative to AI clipping suites that keeps your media on your own machine. Upload a long
video, get a real transcript, find ranked highlight candidates, cut and caption clips in a browser editor, and
render MP4s with FFmpeg. Built as a FastAPI service with multi-tenant isolation, role-based access, a durable
job queue with SSE progress and cancellation, SSRF-guarded URL import, and 75 backend tests. When a provider
is missing it fails with a typed error instead of inventing a transcript.

`Python` · `FastAPI` · `SQLAlchemy` · `FFmpeg` · `faster-whisper` · `Next.js` · `TypeScript`
&nbsp;·&nbsp; [Source](https://github.com/Obiorachibuike/ClipFoam)

### [LeoPay](https://github.com/Obiorachibuike/LeoPay) — multi-tenant payments platform for Nigerian businesses

Payment links, hosted checkout, invoicing, a storefront, payouts and reporting in one workspace, backed by an
append-only double-entry ledger. The engineering is in the controls: workspace roles, audit logs, TOTP
two-factor auth, payout approval thresholds with separation of duties, idempotency keys and signed merchant
webhooks with a retry outbox. Provider adapters are covered by recorded-response contract tests, and the mock
provider used for local flows is blocked in production. Runs locally against PostgreSQL with 110 tests.

`Next.js 15` · `TypeScript` · `PostgreSQL` · `Drizzle ORM` · `Zod` · `Vitest`
&nbsp;·&nbsp; [Source](https://github.com/Obiorachibuike/LeoPay)

### [Taskpro](https://github.com/Obiorachibuike/Taskpro) — offline-first mobile task manager

A React Native app that works with no account, no server and no connection: tasks, projects, categories,
subtasks, tags and reminders are persisted to SQLite before any network call. SQLite is the source of truth —
WAL mode, numbered migrations applied exactly once, transactional writes, soft-delete tombstones and a sync
queue — while Redux Toolkit holds the in-memory projection for fast selectors. Includes calendar views,
notifications, light/dark themes, Detox end-to-end tests and an Android development build configured through Expo.

`React Native 0.81` · `Expo 54` · `Expo Router` · `Redux Toolkit` · `expo-sqlite` · `TypeScript` · `Zod`
&nbsp;·&nbsp; [Source](https://github.com/Obiorachibuike/Taskpro)

### [RepoLens](https://github.com/Obiorachibuike/RepoLens) — repository discovery and intelligence

Describe a project idea and RepoLens turns it into a real GitHub search, ranks the results with a documented
scoring formula, then lets you inspect and analyse any repository it finds — language distribution, file tree,
contributors, commit activity and an eight-section evidence-based report. Every number comes from the GitHub
REST API; when data is unavailable the interface says so instead of filling the gap with placeholders.

`Next.js 15.5` · `React 19` · `TypeScript` · `Tailwind CSS v4` · `PostgreSQL` · `Drizzle ORM`
&nbsp;·&nbsp; [Live](https://repolens-flame.vercel.app) &nbsp;·&nbsp; [Source](https://github.com/Obiorachibuike/RepoLens)
